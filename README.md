# mundial-2026-website
Sitio web interactivo sobre la Copa Mundial de la FIFA 2026, desarrollado con HTML, CSS y JavaScript.
El proyecto presenta información y diferentes secciones relacionadas con el torneo, utilizando tecnologías fundamentales del desarrollo web.
# Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
# Características
- Diseño web responsivo
- Navegación entre diferentes secciones
- Contenido relacionado con el Mundial 2026
- Uso de imágenes y elementos visuales
- Interactividad mediante JavaScript
